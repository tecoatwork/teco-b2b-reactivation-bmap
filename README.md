# B=MAP沉默客户激活

Copyright (c) 2026 tecoatwork

## 用途与方法

B=MAP沉默客户激活。具体工作流程、证据规则及边界见 [SKILL.md](SKILL.md)。

## 输入

客户与市场、产品与销售阶段、实际沟通记录、卡点和联系约定、真实新变化、目标动作及话术语言。

## 交付

客户状态与B=MAP分析、激活思路与执行方法、激活话术、反馈与下一步。

## 安装与启动

下载本仓库并先审查文件，将整个 `teco-b2b-reactivation-bmap` 文件夹放入所用助手支持的 Skill 目录，保留 `SKILL.md` 与 `agents/openai.yaml` 的相对位置。Codex 用户可放入 `~/.codex/skills/`；其他工具以其实际支持方式为准。

启动示例：

> 请使用 teco-b2b-reactivation-bmap。你好，请你告诉我，需要提供什么信息给你。

也可以直接提供输入，Skill会复用已有信息，仅询问关键缺项。

## 依赖与边界

无执行脚本或额外软件依赖。外部研究需要助手具备联网检索能力；本地笔记需要文件读取权限。无法获取的信息会明确标为未核实。只做研究与草稿，不自动发送、修改商业条件或创建自动任务。
